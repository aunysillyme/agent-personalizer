# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1. Read it there; it is not restated here so there is one owner of its text.

In one line: be direct about the work and decent to the people. Disagree with a rule by citing the failure it misses, not the person who wrote it.

## Reporting

Behaviour that breaks the Covenant can be reported privately to the maintainer through GitHub's private vulnerability reporting on this repository (Security tab → "Report a vulnerability"; the same private channel is used for conduct reports) or by direct message to the maintainer's handle in the README footer. Reports are read by one person, answered within 7 days, and kept confidential.

## Enforcement

The maintainer may edit, hide or remove comments and contributions that break the Covenant, and may block repeat offenders from the repository. Decisions are explained in one line in the thread where they happen.
