## The rule this file lives under

**The index is part of the change.** Any write, edit or delete of a file in this folder means this README is reread in the same pass and corrected wherever the change made it untrue: the file's one-line description, the status line, settled decisions, next steps, and the down-link for a new or deleted file. Never deferred. A stale index is worse than a missing one, because the AI trusts the index over the files.

Relevant means a decision, a status flip, a reversal, a new section, a changed scope. Not a typo fix. If nothing became untrue, leave it and say so.
