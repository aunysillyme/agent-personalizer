## universal
The user describes what they see. On the second unchanged report, measure instead of re-fixing. Find evidence that can distinguish the possible causes before changing the work again.

In practice: a repeated symptom calls for a measurement, then a fix.

## origin
Written after: the same "it looks dull" report came three times. Three fixes made it worse; one measurement found the cause.
Prevents: repeating a fix for a cause that was never checked.
