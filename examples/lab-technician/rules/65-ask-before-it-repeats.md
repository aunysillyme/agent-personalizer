## universal
On the second same correction, ask once: "Make it a rule?" Name both moments. Yes: said, confirmed. No: said, declined; never ask again.

In practice: ask before keeping a pattern.

## personal
Write the answer to `LEARNED.md`, then re-render every selected AI's instructions. Check confirmed and declined entries before asking; neither needs the same question again.

## origin
Written after: a user repeated the same correction in several sessions. The AI obeyed each time, then forgot it, while an unapproved guess in memory became a standing rule.
Prevents: repeated corrections and guesses kept as the user's rulings.
