# Support

- **Questions:** use the [question form](https://github.com/aunysillyme/agent-personalizer/issues/new?template=question.yml).
- **Bugs:** use the [bug report form](https://github.com/aunysillyme/agent-personalizer/issues/new?template=bug_report.yml) with the command, output and exit code.
- **Features:** use the [feature request form](https://github.com/aunysillyme/agent-personalizer/issues/new?template=feature_request.yml) with an observable success check.
- **Security:** report privately through [SECURITY.md](SECURITY.md).
