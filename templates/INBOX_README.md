# Inbox

*Where the AI leaves things for me and I leave things for the AI. One file per item, dated, named for the topic. Never one growing file.*

## Rules

- **One file per item.** `YYYY-MM-DD-<topic>.md`. No appending to yesterday's file.
- **Finished items are deleted, not marked done.** Version control holds the history. A file marked RESOLVED still reads as open to the next AI that looks in here.
- **Machine-generated reports are the one exception:** a report that is rebuilt every run is overwritten in place, carries `type: log` in its frontmatter, and says outright that it is derived, never a source of truth.
- **If a live document cites an inbox file, repoint the citation before deleting.**
